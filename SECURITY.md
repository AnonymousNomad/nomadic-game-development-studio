# Security policy

This is a **local development preview**, not an internet-facing app. Run the HTTP servers only on loopback (127.0.0.1) and never publish, reverse-proxy or port-forward the ports.

Do not commit credentials, send bearer tokens to models, give the demo MCP adapters arbitrary shell access, or connect any untrusted game project without a separate backup and security review.

If you find a security defect, contact the repository owner privately through GitHub. Exclude private project contents, credentials and browser profile data from reports.
